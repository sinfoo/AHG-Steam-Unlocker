# AHG Unlocker — Product Context

## Product Purpose
AHG Unlocker is a desktop tool (Electron + React) that lets users install and manage unlocked Steam games via manifest injection. It bypasses Steam's native DRM by downloading game manifests from community mirror repos, writing SteamTools-compatible `.lua` activation files, and managing the entire install lifecycle — from discovery to DLC registration — through a dark-themed React UI.

## Users
Gamers who want free Steam games. Casual-to-intermediate users who want a simple, one-click experience: find a game, click install, play. They use this in a dimly lit room on a gaming PC, often with Discord open in the background. They expect game-launcher polish (smooth animations, cover art, search) but with the power of a modding tool underneath.

## Register
product — the design serves the tool's functionality, not the other way around.

## Brand Tone
Gamer aesthetic with purpose. Dark, confident, energetic — inspired by Discord and modern game launchers. Violet accent as the signature color. Not sterile, not corporate, not try-hard. The UI should feel like a tool a gamer built for gamers.

## Anti-References
- No SaaS/enterprise design (no white, no blue, no Linear/Stripe clone)
- No generic AI startup aesthetic (no glassmorphism as default, no gradient text, no purple-orange)
- No skeuomorphic "gamer" clichés (no RGB rainbows, no cyberpunk borders, no neon glitch effects)

## Strategic Principles
1. Dark is not a default — it's a requirement. Gaming PCs live in dim rooms.
2. Performance matters as much as appearance. Smooth 60fps UI.
3. Every animation serves understanding, not decoration.
4. One-click install is the north star. The UI gets out of the way.
5. Consistency across all 16 components. Single design language.
