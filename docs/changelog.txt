  ✅ FIX: No longer prevents accessing the app on random restarts

🔧 tryRepoForGame Returning Success with 0 Manifests
  ❌ ISSUE: Empty branch ZIP reported success, Steam showed 0B game
  ✅ FIX: Returns null when manifestCount === 0, allowing fallbacks

🔧 ryuu.lol Unconditional foundRepo
  ❌ ISSUE: foundRepo set before processing ZIP entries
  ✅ FIX: Only set when a manifest is actually written

🔧 Bundled Repo Lua in Old OnStartup Format
  ❌ ISSUE: SteamTools v3 ignores old OnStartup wrapper
  ✅ FIX: Always overwrites with addappid(appid)\n

🔧 depots: {} Causing 0B in Steam

  ✅ FIX: Reverted to v0.70 format (no depots field)

🔧 10s HTTP Timeout Causing Silent Failures

  ✅ FIX: Increased to 30s
